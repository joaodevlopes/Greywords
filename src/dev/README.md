# Só para desenvolvimento

`catalog.sample.json`: catálogo de exemplo carregado **apenas** em `npm run dev` quando `public/catalog.json` ainda não existe.
Títulos, palestrantes e IDs do YouTube são reais (canal TED, conferidos no oEmbed); **duração, palavras/min, % pouco comuns, nível e palavras-chave são fictícios**.
O build de produção não inclui este arquivo.
